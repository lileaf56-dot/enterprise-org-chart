# 企業組織架構管理系統 (Enterprise Organization Architecture Suite)

> 最新發布版本：`v1.0.0-final`（2026-11-24）

## 快速啟動
- 雙擊執行目錄下的 **`啟動服務.bat`**。
- 瀏覽器訪問：**`http://127.0.0.1:9527`**。

## 目錄架構
- `index.html`：系統正式運行主程式。
- `start_server.py`：固定端口 9527 本地 HTTP 服務。
- `啟動服務.bat`：一鍵啟動腳本。
- `release/v1.0.0-final/`：**v1.0.0 正式存檔歸檔包**（包含完整程式、種子數據 JSON 與說明文檔）。
